# Tic Tac Toe

A browser-based Tic Tac Toe game built with HTML, CSS, and JavaScript featuring emoji game pieces, winner detection, and a custom SVG victory animation.

## About

This project was completed during the PERSEVERE Full MERN Stack Software Development Bootcamp. It demonstrates core JavaScript concepts by implementing a fully functional two-player Tic Tac Toe game with turn tracking, win detection, draw detection, and an animated celebration for the winner.

## Live Demo

🎮 **Play the game here:**

https://graceelliott8374-tech.github.io/tic-tac-toe/

## Features

- Two-player gameplay
- Emoji game pieces (❌ and ⭕)
- Automatic winner detection
- Draw detection
- Restart game button
- Custom SVG victory animation
- Responsive layout
- Clean, organized JavaScript

## Built With

- HTML5
- CSS3
- JavaScript (ES6)
- SVG Animation
